JCOUP 관리자 v2.4.1 정적 검증 결과
- JavaScript 구문 검사: 통과
- 관리자 내부 overlay/iframe 학생 테스트 UI 제거
- `학생 화면 테스트` → window.open 기반 별도 새 창 방식으로 변경
- 관리자 창/로그인 상태는 유지하고 학생 테스트 창만 별도 표시
- 테스트 payload는 same-origin postMessage로 전달
- previewRun 식별값으로 현재 테스트 창/세션 데이터만 적용
- 팝업 차단 예외 안내 추가
- v2.4.0 좌석 편집(빈 자리/빈 행 포함), 명단 파일 자동 인식, 실시간 감독 기능 유지
- Firestore Rules 변경 불필요

권장 실제 확인
1) 관리자 로그인 상태에서 수행평가 > 학생 화면 테스트
2) 새 창이 열리고 관리자 창이 그대로 유지되는지 확인
3) 목록/인증/응시 화면 각각 시작 확인
4) 테스트 답안 작성/제출 후 관리자 감독/CSV에 기록이 생기지 않는지 확인
5) A/B/C/E 실제 좌석 저장 후 새로고침 및 감독 화면 배열 유지 확인
