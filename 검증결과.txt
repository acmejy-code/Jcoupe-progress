[권장 실기 테스트]
1. 3분짜리 테스트 평가 생성
2. 관리자에서 평가 시작 → 관리자/학생 남은 시간 감소 확인
3. 4자리 학번 / 5자리 학번 각각 인증 확인
4. 학생이 탭 전환, 복사, 붙여넣기 → 감독 카드 횟수 확인
5. 관리자 전체 +5분 → 학생 타이머 즉시 증가 확인
6. 특정 학생 개인 +5분 → 해당 학생만 증가 확인
7. 시간 종료 → 미제출 학생 자동 제출 확인
8. 제출 학생 '재응시 허용' → 다시 답안 수정 가능 확인
9. 이전 수업에 '다음 시간 시작점' 저장 → 다음 실제 수업의 달력 빈 카드에 표시 확인
