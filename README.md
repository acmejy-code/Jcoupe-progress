# JCOUP 관리자 v3.1.0 — 수행평가 반별 완전 분리 + 평가목록 접기

## 핵심 변경
- 수행평가 마감/자동확정을 평가 ID별 독립 작업으로 분리했습니다. 한 평가의 지연·실패가 다른 평가를 기다리게 하지 않습니다.
- 학생 입장 열기, 시험 시작, 평가 종료는 선택한 평가 문서만 변경하며 다른 평가 상태를 조회·수정하지 않습니다.
- 미제출 강제확정 및 실패 안전 종료도 해당 assessmentId 하위 attempts만 처리합니다.
- 평가 목록 사이드 패널을 ◀/▶ 버튼으로 접고 펼칠 수 있으며 상태를 브라우저에 기억합니다.
- 기존 평가/학생/답안/진도 데이터 구조는 유지합니다. Firestore Rules 변경 없음.

학생 포털은 v1.6.8을 함께 사용하면 선택한 반에 해당하는 WAITING/OPEN 평가만 목록에 표시되어 다른 반 평가가 학생 화면에 섞이지 않습니다.
