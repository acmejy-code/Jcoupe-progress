# 제이쿱 수업 통합 제어 시스템 v2.4.3

## 이번 수정의 핵심
v2.4.2에서 `세로줄 수`를 **좌우로 보이는 세로 좌석 열의 개수**로 해석한 것이 사용자 의도와 달랐습니다.

v2.4.3에서는 설정 의미를 다음처럼 바로잡았습니다.

- `세로줄 수` → **`세로 한 줄 좌석 수`**
- 의미: **칠판에서 교실 뒤쪽으로 한 세로줄에 몇 개의 좌석을 놓을지** 설정
- 좌우로 몇 열이 필요한지는 학생 수와 빈 자리에 따라 자동 계산
- 학생은 각 세로줄에서 **앞 → 뒤**로 학번순 배치된 뒤 다음 오른쪽 열로 넘어감

예: 23명
- `세로 한 줄 좌석 수 = 4` → 앞→뒤 4석, 좌우 6열
- `세로 한 줄 좌석 수 = 5` → 앞→뒤 5석, 좌우 5열
- `세로 한 줄 좌석 수 = 6` → 앞→뒤 6석, 좌우 4열

즉 숫자를 키우면 가로 열이 늘어나는 것이 아니라, **교실 앞뒤 방향의 좌석 수가 늘어나고 좌우 열 수는 줄어드는 구조**입니다.

## 좌석 배치 UI
- 좌석 제목에 `세로 한 줄 N석 · 좌우 M열`을 함께 표시
- 각 학생 카드에 `왼쪽 N번째 열 · 앞에서 M번째` 표시
- `학번순 초기배치`는 각 열의 앞→뒤를 먼저 채움
- `+ 빈 자리` 유지
- `+ 빈 행`은 교실 뒤쪽에 빈 행을 추가하며 `세로 한 줄 좌석 수`도 1 증가
- `끝 빈칸 정리` 유지
- `창가 표시` 유지
  - 왼쪽/오른쪽 각각 `복도쪽 창가 / 외벽 창가 / 표시 안 함`
  - `좌우 바꾸기` 지원

## 실시간 감독 화면
저장된 좌석의
- 앞→뒤 좌석 수
- 좌우 열 수
- 빈 자리
- 복도쪽/외벽 창가 방향
을 좌석 편집 화면과 동일하게 표시합니다.

## 기존 v2.4.2 좌석 데이터 호환
- v2.4.2의 `flow=VERTICAL_LINES` 좌석은 기존 화면의 물리적 좌석 위치가 최대한 유지되도록 자동 변환해 읽습니다.
- 새로 저장하면 `flow=VERTICAL_DEPTH`와 `seatsPerVerticalLine`이 기록됩니다.
- 창가 방향 `leftSide / rightSide`는 그대로 유지됩니다.

## 학생 화면 테스트
v1.4.1의 새 창 테스트 방식은 그대로 유지합니다.
- 관리자 화면 유지
- 학생 포털은 새 창/새 탭
- 테스트 모드는 실제 응시 데이터에 저장하지 않음
