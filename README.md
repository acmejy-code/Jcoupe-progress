# JCOUP 관리자 v2.6.4 — 학생 포털 달력 공개 데이터 확장

기준: 관리자 v2.6.3 전체 기능을 유지하면서 학생 포털의 학사일정·수업진도 달력에 필요한 공개 데이터를 추가합니다.

## v2.6.4 추가 개선
- 학생 포털 발행 시 학기 시작/종료일, 학사일정, 수업 없는 날짜, 주간 시간표를 공개 메타데이터에 함께 발행
- 각 반 공개 문서에 학기 전체 공개 수업 기록(calendarRecords)을 포함
- 관리자에서 숨김/미진행 처리한 예정 수업은 학생 달력에서 다시 나타나지 않도록 scheduleSkips를 함께 발행
- 아직 실제 진도 기록이 없는 반도 달력 표시를 위해 공개 반 문서를 생성

## 배포
관리자 저장소 전체를 교체한 뒤 로그인하여 **학생 포털 발행**을 한 번 실행하세요. 기존 수행평가·대기실·감독 확대 기능은 그대로 유지됩니다.
