# JCOUP 관리자 v2.6.9 — 전원 제출 즉시 종료·마감 대기 단축

## 누적 기준
v2.6.8의 강제확정 감사정보, 최종답안 복구 후보, 평가 삭제, 개인 1분 단위 추가시간, 입장/제출 안정화 기능을 모두 포함합니다.

## v2.6.9 핵심 수정
- 대상 반 학생 전원이 `SUBMITTED` 상태가 되면 시험시간이 남아 있거나 0초 후 유예시간이 남아 있어도 평가를 즉시 `CLOSED` 처리합니다.
- 전원 제출 여부는 현재 평가의 대상 반 학생 명단 전체와 대조하므로, 미접속 학생이 있는 상태에서는 조기 종료되지 않습니다.
- 마지막 학생의 제출 상태가 Firestore 실시간 감시에 반영되는 즉시 종료 여부를 다시 확인하여 기존 3초 주기 대기까지 줄였습니다.
- 미제출 학생이 남은 경우에만 시험 종료 후 통신 유예를 적용하며, 유예시간은 30초에서 15초로 단축했습니다.
- 15초 후에도 미제출이면 서버의 마지막 저장 답안을 기존 방식대로 강제 확정한 후 평가를 종료합니다.
- Firestore Rules 변경 없음. 학생 포털 v1.6.7은 그대로 사용할 수 있습니다.
