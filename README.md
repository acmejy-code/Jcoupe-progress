# 제이쿱 수업 통합 제어 시스템 v2.0

기존 `독서토론과 글쓰기 진도관리기 v1.1`을 학년도·학년·과목이 달라져도 계속 누적 확장할 수 있도록 **수업 프로젝트 기반 구조**로 개편한 첫 버전입니다.

## 1. 이번 단계의 핵심

- 시스템 공식 명칭: **제이쿱 수업 통합 제어 시스템**
- 기존 2026학년도 독토글을 첫 수업 프로젝트로 등록
  - 프로젝트 ID: `2026-2-G2-DOKTOGUL`
  - 2026학년도 / 2학기 / 2학년 / 독서 토론과 글쓰기
  - A·B·C·E반
- 기존 기능 유지
  - 오늘 수업
  - 월간 달력
  - 반별 진도
  - 기록 조회
  - 예정수업 숨김/복원
  - 학교 일정
  - 고정 참고과목(심화국어)
  - JSON 백업/복원
  - Google 로그인 + Firestore 실시간 동기화
- 신규 기능
  - 수업 프로젝트 선택
  - 새 프로젝트 생성 / 수정 / 복제
  - 학년도·학기·학년·과목·반·기간 분리
  - 프로젝트별 시간표와 단원 빠른 선택 관리
  - 수업 기록에 `학생 포털 공개 대상` 표시
  - 기존 v1.1 데이터 자동 이전 지원

## 2. 기존 데이터 이전

### 이 기기(localStorage)
기존 키 `doktogul_progress_v1_records`에 데이터가 있고 새 프로젝트 저장소가 비어 있으면,
2026 독토글 프로젝트로 **복사**합니다. 기존 키는 삭제하지 않습니다.

### Firestore
기존 경로:

`users/{uid}/lessonRecords/{recordId}`

새 경로:

`users/{uid}/courseProjects/2026-2-G2-DOKTOGUL/lessonRecords/{recordId}`

로그인 시 새 프로젝트에 기록이 하나도 없고 기존 경로에 기록이 있으면 자동으로 **복사**합니다.
기존 기록은 삭제하지 않습니다.

## 3. 앞으로의 누적 구조

예시:

- 2026학년도
  - 2학년 / 독서 토론과 글쓰기
- 2027학년도
  - 1학년 / 공통국어
  - 2학년 / 문학
- 2028학년도
  - 필요 과목 추가

수업 프로젝트를 새로 만들거나 기존 프로젝트를 복제하여 이어가면 됩니다.

## 4. 학생 포털 연결

이번 v2.0에서는 학생 포털용 필드를 준비만 합니다.

수업 기록에서:
- `학생 포털 공개 대상으로 표시`

를 켤 수 있습니다.

다음 단계에서 **독-토-글 수업 종합 포털 v1.0**을 제작하고,
관리자 시스템의 공개 대상 진도만 `publicCourses` 영역에 발행하도록 연결합니다.

교사용 메모는 학생 공개 데이터에 포함하지 않습니다.

## 5. 배포

기존 저장소 `acmejy-code/doktogul-progress`의 파일을 이 버전 파일로 교체해도 됩니다.
다만 장기적으로 저장소 이름도 `jcoop-class-control`처럼 범용 명칭으로 바꾸는 것을 권장합니다.

Firebase 프로젝트는 현재 `doktogul-progress`를 그대로 사용해도 기능상 문제 없습니다.
향후 여러 과목까지 확대된 후 Firebase 프로젝트명만 별도로 바꾸는 작업은 필수 사항이 아닙니다.

## 7. 적용 순서

1. 현재 GitHub 저장소 파일 백업
2. 본 v2.0 전체 파일 업로드
3. `firestore.rules`를 Firebase Firestore Rules에 반영
4. GitHub Pages 자동 배포 확인
5. Google 로그인
6. 기존 기록 자동 복사 안내 확인
7. 오늘 / 달력 / 반별 진도 / 기록 조회 점검
8. `수업 프로젝트` 탭에서 2026 독토글 프로젝트 확인
