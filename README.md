# 제이쿱 수업 통합 제어 시스템 v2.1

v2.0 프로젝트 기반 구조에 **학생 포털 자동 발행 기능**을 추가한 전체 배포본입니다.

## 핵심 변경
- 수업 기록의 `학생 포털 공개 대상` 체크를 실제 공개 데이터와 연결
- 수업 기록 저장/삭제 후 학생 포털 공개 데이터 자동 갱신
- `수업 프로젝트` 탭에 `학생 포털 지금 발행` 버튼 추가
- `학생 포털 열기` 버튼 추가
- 공개 데이터에는 교사용 `memo`를 포함하지 않음
- 공개 전용 Firestore 경로 `publicCourses/{projectId}` 사용
- 학생 포털은 로그인 없이 공개 데이터만 읽음

## 공개되는 항목
- 날짜
- 교시
- 수업 유형
- 차시
- 수업 제목/지문명
- 실제 진행 내용
- 다음 수업 시작점

## 공개되지 않는 항목
- 교사용 메모 / 미진행 사유
- 관리자 계정 정보
- 원본 관리자 데이터 전체

## 적용 순서
1. 본 v2.1 전체 파일을 `Jcoupe-progress` 로컬 폴더에 덮어쓰기
2. GitHub Desktop Commit → Push
3. GitHub Actions 초록 체크 확인
4. Firebase Firestore Rules에 `firestore.rules` 전체 내용 반영 후 게시
5. 관리자 `수업 프로젝트` 탭에서 `학생 포털 지금 발행` 클릭
6. `학생 포털 열기`에서 A/B/C/E반 진도 확인

## 일상 사용
Firebase 규칙 적용이 끝난 뒤에는 수업 기록을 저장할 때 학생 공개 대상 진도가 자동으로 다시 발행됩니다.
공개를 원하지 않는 기록은 `학생 포털 공개 대상` 체크를 해제한 뒤 저장하면 다음 자동 발행 때 제외됩니다.
