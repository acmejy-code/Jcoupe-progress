# 제이쿱 수업 통합 제어 시스템 v2.4.1

## 이번 개선
- `학생 화면 테스트`를 관리자 화면 내부 iframe 전환 방식에서 **별도 새 창 방식**으로 변경
- 관리자 로그인/관리 화면은 그대로 유지하고, 학생 테스트 화면을 옆 창에서 동시에 확인 가능
- 테스트 시작 시 수행평가·반·학생·시작 화면(목록/인증/응시)을 선택하는 기존 기능 유지
- 새 창이 차단되면 팝업 허용 안내 표시
- 학생 테스트 창과 관리자 창은 same-origin `postMessage`로 테스트 데이터만 전달
- 테스트 답안은 실제 Firestore 응시 기록·감독 현황·CSV에 저장되지 않음
- v2.4.0의 명단 파일 자동 인식, 좌석 편집(빈 자리/빈 행 포함), 실시간 좌석 감독 기능 유지

## 좌석 배치
`수행평가 > 학생 명단·좌석 > 좌석 배치`에서 수행평가 생성 전에도 실제 교실 좌석을 저장할 수 있습니다.
학생 카드를 드래그하고 빈 자리/빈 행을 추가한 뒤 `좌석 배치 저장`을 누르십시오.

## 학생 화면 테스트
1. `수행평가 > 학생 화면 테스트`
2. 수행평가 / 반 / 테스트 학생 / 시작 화면 선택
3. `새 창에서 테스트 학생 열기` 클릭
4. 별도 창에서 실제 학생 포털 UI로 응시 과정을 테스트
5. 관리자 창에서는 동시에 좌석 감독 화면 등을 확인

※ 브라우저가 팝업을 막으면 `acmejy-code.github.io`의 팝업을 허용해야 합니다.
