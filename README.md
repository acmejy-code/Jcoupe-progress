# JCOUP 관리자 v2.6.3 — 대기실 재입장 + 응시코드/시험시간 감독 확대

## 기준
- v2.6.2 대기실 재입장/기기 인계 기능을 그대로 포함합니다.
- 실제 기존 운영본 v2.6.1에서 발견된 현장 개선사항을 통합한 다음 교체본입니다.

## v2.6.3 추가 개선
1. 수행평가 상단의 검정색 **응시코드**를 클릭하면 현재 감독 좌석표 크기에 맞춘 대형 중앙 화면으로 확대됩니다.
   - 학생들이 교실 앞 화면에서 쉽게 확인할 수 있도록 큰 글씨로 표시합니다.
   - 빈 배경 클릭, 닫기 버튼, ESC로 닫을 수 있습니다.
2. **남은 시험시간** 영역을 클릭하면 좌석표 가로폭에 맞춘 대형 타이머가 열립니다.
   - 높이는 좌석 카드 약 2줄에 해당하도록 자동 계산합니다.
   - 처음에는 좌석표 위에 겹쳐 표시되고, 상단 제목 바를 드래그하여 자유롭게 이동할 수 있습니다.
   - 기존 5분 이하 경고색/시간 종료 표시를 대형 타이머에도 동기화합니다.
3. v2.6.2의 대기실 재입장/기기 인계 및 감독 상태 세분화를 유지합니다.

## 배포
관리자 GitHub `acmejy-code/Jcoupe-progress`에 이 폴더의 전체 파일을 교체 배포합니다.
대기실 재입장/기기 인계까지 함께 적용하려면 학생 포털 v1.6.2와 본 패키지의 `firestore.rules`도 함께 배포해야 합니다.
