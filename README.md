# 제이쿱 수업 통합 제어 시스템 v2.3.1

## 이번 개선
- 수행평가 학생 명단에 **4자리·5자리 학번 모두 지원**
  - 예: `2207`, `20101`
- 학생 명단 입력 시 학번 형식 검증 및 중복 학번 확인
- 학생 명단 **파일 불러오기** 추가
  - Excel(.xlsx/.xls), CSV, TSV, TXT
  - 첫 행에 `학번`, `이름`이 있으면 자동 인식
  - 파일을 불러오면 명단 확인 영역에 자동 표시
- 좌석 초기 배치는 기존과 동일하게 **학번 오름차순**
- 기존 수행평가 응시 관리, 자료실, 진도/달력 기능 유지

## 명단 파일 예시
| 학번 | 이름 |
|---|---|
| 20101 | 홍길동 |
| 20102 | 김민수 |

반은 관리자 화면에서 선택하므로 파일에 반 정보는 없어도 됩니다.

## 주의
Excel 파일 읽기는 브라우저에서 SheetJS 라이브러리를 불러와 처리합니다. 학교 네트워크에서 외부 CDN이 차단된 경우 CSV 파일로 저장하여 업로드하면 됩니다.
