# JCOUP 관리자 v3.4.0 — 실전 수행평가 감독 안정화

현재 GitHub 게시본 v3.3.0을 기준으로 수정한 전체 교체본입니다.

## 유지되는 핵심
- 평가 ID별 독립 운영
- 수행평가 목록 접기
- Firestore 서버 스냅샷 기준 평가 목록
- 3초 attempts 전체 재조회/강제제출 루프 제거
- 평가 종료 시 상태 중심 마감, 답안 데이터 보존
- Firestore 쿼터 보호 구조 유지

## v3.4.0 변경
학생 포털 v1.7.0의 60초 heartbeat 정책에 맞춰 감독 판정 기준을 조정했습니다.
- 마지막 신호 75초 이내: 정상
- 75초 초과: 연결 지연
- 150초 초과: 접속 이상

감독 이벤트는 참고 정보로만 표시합니다.
- 3초 이상 화면 숨김: 화면 이탈 참고 기록
- 실제 copy / paste만 기록
- 태블릿 키보드 열기·닫기, 단순 텍스트 선택, 길게 누르기, 컨텍스트 메뉴는 신규 학생 포털에서 기록하지 않음

학생 포털은 반드시 v1.7.0과 함께 배포하는 것을 권장합니다.
