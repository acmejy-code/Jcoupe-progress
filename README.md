# JCOUP 관리자 v2.6.8 — 시험 종료 감사·복구 후보 강화

## 누적 기준
v2.6.7의 평가 삭제, 개인 +1분/직접 분 단위 추가시간, 입장/제출 안정화 기능을 모두 포함합니다.

## v2.6.8 핵심 수정
- 시험 종료 후 학생 자체 제출을 기다리는 통신 유예시간을 30초로 통일했습니다. 0초 이후 답안 수정은 불가합니다.
- 관리자가 강제 확정할 때 답안 본문은 건드리지 않고, 강제확정시각·강제확정 당시 마지막 서버저장시각·마지막 기기수정시각·개인 마감시각을 감사정보로 남깁니다.
- 학생 기기에 서버 제출본과 다른 마지막 입력 백업이 발견되면 세션 문서의 복구 스냅샷으로 보존할 수 있습니다.
- 응답 CSV에 개인마감시각/강제확정 감사정보/복구후보 및 복구문항을 함께 내보냅니다.
- Firestore Rules 변경 없음: 기존 세션 업데이트 권한 범위 안에서 복구 스냅샷을 저장합니다.
