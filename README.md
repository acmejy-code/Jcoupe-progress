# JCOUP 관리자 v3.1.1 — 서버 확정형 평가 상태/삭제 + 중복 평가 방지

v3.1.0의 반별 독립 운영과 평가 목록 접기 기능을 유지하면서, 수행평가 상태 변경·삭제가 화면에서만 반영된 것처럼 보였다가 새로고침 후 되돌아오는 현상을 추적하기 위한 안정화 버전입니다.

## 핵심 변경
- 수행평가 종료 후 Firestore 서버 원본(private)과 학생 공개본(public)이 모두 `CLOSED`인지 서버에서 직접 재확인합니다.
- 수행평가 삭제 후 private/public 문서가 서버에서 실제로 사라졌는지 직접 재확인합니다.
- Firestore의 로컬 pending write를 관리자 평가 목록에 성공 상태처럼 즉시 반영하지 않습니다.
- 평가 목록과 상세 화면에 평가 ID를 표시해 같은 제목의 서로 다른 평가를 구분할 수 있습니다.
- 새 수행평가 저장 중 저장 버튼을 잠가 연속 클릭으로 서로 다른 평가 ID가 중복 생성되는 것을 방지합니다.
- 제목·대상 반·시험시간·문항 수가 같은 평가가 이미 있으면 새 평가 생성 전에 경고합니다.
- 삭제/종료 후 동일 조건의 다른 평가 ID가 남아 있으면 명확히 안내합니다.

## 유지 사항
- 평가 ID별 독립 운영
- 한 평가의 지연/종료 실패가 다른 평가의 입장·시작·종료를 막지 않음
- 평가 목록 접기/펼치기
- 기존 답안/명단/좌석/수업 데이터 구조 유지
- Firestore Rules 변경 없음
- 학생 포털 v1.6.8 그대로 사용 가능
