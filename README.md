# 제이쿱 수업 통합 제어 시스템 v2.4.2

## 이번 개선
- 좌석 설정의 `한 줄 좌석 수`를 **`세로줄 수`**로 변경
- 세로줄은 **칠판·교탁을 바라봤을 때 왼쪽→오른쪽으로 나뉘는 앞뒤 좌석 열**을 의미
- `학번순 초기배치` 시 학생을 가로 방향이 아니라 **각 세로줄의 앞→뒤 방향**으로 먼저 채운 뒤 다음 세로줄로 배치
- 세로줄 수를 바꾸면 현재 학생 순서를 새 세로줄 수에 맞춰 자동 재배치
- 좌석 편집 버튼 영역에 **`창가 표시`** 추가
- 좌측/우측을 각각 `복도쪽 창가 / 외벽 창가 / 표시 안 함`으로 설정 가능
- 저장한 좌우 창가 방향을 좌석 편집 화면과 수행평가 실시간 감독 화면에 동일하게 표시
- 기존 v2.4.1 학생 테스트 새 창 방식과 테스트 데이터 비저장 구조 유지

## 기존 좌석 데이터 호환
- 기존 좌석 문서는 그대로 읽습니다.
- 빈 자리 없이 학번순으로만 저장된 기존 기본 좌석은 화면에서 자동으로 세로줄 기준 배치로 해석합니다.
- 사용자가 직접 만든 빈 자리/수동 좌석 배치는 임의로 재배열하지 않습니다.
- 새로 저장하면 `verticalLines`와 `flow=VERTICAL_LINES`가 함께 기록됩니다.

## 좌석 배치 사용법
1. `수행평가 > 학생 명단·좌석 > 좌석 배치`
2. `세로줄 수`에서 칠판을 바라봤을 때 보이는 세로 좌석 열 수 선택
3. 필요하면 `학번순 초기배치`
4. `창가 표시`에서 왼쪽/오른쪽의 복도쪽 창가·외벽 창가 설정
5. 학생 카드를 드래그하고 빈 자리/빈 행을 조정
6. `좌석 배치 저장`

예: 화면 왼쪽이 복도쪽 창가, 오른쪽이 외벽 창가인 교실은
- 왼쪽: `복도쪽 창가`
- 오른쪽: `외벽 창가`
로 설정합니다.

## 학생 화면 테스트
1. `수행평가 > 학생 화면 테스트`
2. 수행평가 / 반 / 테스트 학생 / 시작 화면 선택
3. `새 창에서 테스트 학생 열기` 클릭
4. 별도 창에서 실제 학생 포털 UI로 응시 과정을 테스트
5. 관리자 창에서는 동시에 좌석 감독 화면 등을 확인

※ 브라우저가 팝업을 막으면 `acmejy-code.github.io`의 팝업을 허용해야 합니다.
