# 제이쿱 수업 통합 제어 시스템 v2.3.2

## 이번 개선
- 학교에서 사용하는 실제 명렬표 형태의 Excel 파일 인식 강화
- 파일 첫 행이 머리글이 아니어도 상단 30행 안에서 실제 머리글 행을 자동 탐색
  - 예: 1행 `교시`, 2행 `2학년3반`, 3행 공백, 4행 `학년 / 반 / 번호 / 학번 / 이름`
- `학번 + 이름` 열이 있으면 해당 값을 직접 사용
- 학번 열이 없거나 수식 결과를 읽지 못해도 `학년 + 반 + 번호 + 이름` 열이 있으면 5자리 학번을 자동 생성
  - 예: `2 / 01 / 22` → `20122`
  - 예: `2 / 03 / 7` → `20307`
- 줄바꿈·공백이 포함된 머리글도 자동 정규화하여 인식
- 기존 4자리·5자리 학번 지원, 중복 검사, 학번 오름차순 좌석 생성 유지
- Excel(.xlsx/.xls), CSV, TSV, TXT 불러오기 유지
- 기존 수행평가 응시 관리, 자료실, 진도/달력 기능 유지

## 지원하는 명단 예시 1
| 학번 | 이름 |
|---|---|
| 20101 | 홍길동 |
| 20102 | 김민수 |

## 지원하는 명단 예시 2
파일 위쪽에 교시/학급 안내가 있고 실제 표가 아래에서 시작해도 됩니다.

| 순서 | 학년 | 반 | 번호 | 학번 | 이름 |
|---:|---:|---:|---:|---:|---|
| 1 | 2 | 01 | 22 | 20122 | 홍길동 |
| 2 | 2 | 02 | 09 | 20209 | 김민수 |

`학번` 열에 TEXTJOIN 등의 Excel 수식이 있어도 저장된 계산값을 우선 읽으며, 값이 비어 있거나 유효하지 않으면 학년·반·번호로 학번을 다시 만듭니다.

## 주의
- 학생 이름 열의 머리글은 `이름`, `성명`, `학생명`, `학생이름` 등을 지원합니다.
- Excel 파일 읽기는 브라우저에서 SheetJS 라이브러리를 불러와 처리합니다. 학교 네트워크에서 외부 CDN이 차단된 경우 CSV 파일로 저장하여 업로드하면 됩니다.
