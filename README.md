# JCOUP 관리자 v2.6.5 — 시험 종료 강제 자동 제출 안정화

기준: 관리자 v2.6.4의 학생 포털 학사일정 달력 연동, 대기실 재입장, 응시코드 확대, 이동형 시험시간 창 등 누적 기능을 모두 유지합니다.

## v2.6.5 추가 개선
- 시험시간 판정 시 Firestore 서버 시각을 주기적으로 동기화하여 관리자 PC 시계 오차의 영향을 줄임
- 공통 시험시간이 끝난 학생은 학생 브라우저 상태와 관계없이 관리자 감독 화면에서 마지막 서버 저장 답안을 `SUBMITTED`로 강제 확정
- 개인 추가시간이 있는 학생은 자기 추가시간이 끝날 때까지 자동 제출 대상에서 제외
- 모든 미제출 학생의 유효 시간이 끝나면 평가 상태를 자동으로 `CLOSED`로 전환
- 교사가 `평가 종료`를 누르면 아직 미제출인 학생의 마지막 서버 저장 답안을 먼저 일괄 확정한 뒤 종료
- 강제 제출은 Firestore transaction으로 처리하여 학생의 마지막 자동 저장과 충돌할 때 최신 서버 저장 상태를 다시 확인
- 제출 사유(`MANUAL`, `TIME_EXPIRED`, `TEACHER_CLOSE`)를 기록하고 CSV에 `제출사유` 열 추가
- 재응시 허용 시 이전 강제 제출 사유와 강제 확정 표시를 초기화

## 중요 동작
- 자동 제출의 기준 답안은 **시험 종료 시점까지 Firestore 서버에 마지막으로 저장된 답안**입니다.
- 학생 기기가 꺼져 있거나 브라우저가 닫혀 있어도, 교사용 관리자 페이지가 시험 감독 중 열려 있으면 종료 시각을 감지하여 서버의 마지막 저장 답안을 확정합니다.
- 학생별 추가시간이 설정된 경우 해당 학생의 마감 시각까지 평가를 자동 종료하지 않습니다.

## 배포
관리자 저장소 전체를 이 폴더 내용으로 교체하세요. Firestore Rules는 v2.6.4와 동일하므로 이번 개선만을 위해 다시 게시할 필요가 없습니다.
