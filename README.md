# 제이쿱 수업 통합 제어 시스템 v2.2.0

기존 v2.1.0의 수업 진도 관리·학생 포털 자동 발행 기능을 유지하면서 **Google Drive 링크형 수업 자료실 관리**를 추가한 전체 배포본입니다.

## v2.2.0 주요 추가 기능

- `수업 자료` 메뉴 추가
- Google Drive 공유 링크 등록
- 자료명 / 설명 / 분류 / 파일 형식 관리
- 전체 반 또는 A/B/C/E 등 특정 반 공개
- 공개 / 비공개 설정
- 자료 수정·삭제
- 학생 포털 공개 자료 자동 발행
- 백업 JSON에 수업 자료 목록 포함
- 기존 v2.1 백업도 복원 가능
- Firebase Storage 사용하지 않음

## 무료 운영 구조

1. 선생님이 Google Drive에 PDF/PPTX/HWP 등의 파일을 업로드합니다.
2. Drive 공유 설정을 `링크가 있는 모든 사용자 → 뷰어`로 설정합니다.
3. 공유 링크를 관리자 시스템의 `수업 자료`에서 등록합니다.
4. 시스템은 Firestore에 파일 자체가 아닌 자료 정보와 Drive 링크만 저장합니다.
5. 학생 포털은 공개 자료 목록을 Firestore에서 읽고 Drive 미리 보기/다운로드 링크를 제공합니다.

## 배포 시 필수

- `firestore.rules`를 Firebase Console의 Firestore 규칙에 적용하십시오.
- 학생 포털은 `Jcoupe-class-portal v1.2.0`과 함께 배포하십시오.
- GitHub Pages 배포 구조는 기존과 동일합니다.

## 주의

자료를 시스템에서 삭제해도 Google Drive의 원본 파일은 삭제되지 않습니다.
Drive 파일의 공유 권한을 제한하면 학생 포털에서 자료가 보여도 학생이 열지 못할 수 있습니다.
