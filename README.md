# JCOUP 관리자 v2.6.1 — 수행평가 대기실 / 공통 시험 시작

## 새 응시 흐름
1. 평가를 만든 뒤 `학생 입장 열기`
2. 학생은 학번·이름·응시코드로 인증하여 대기실 입장
3. 대기 중에는 문항이 공개되지 않고 시험시간도 흐르지 않음
4. 관리자는 좌석 감독 화면에서 대기실 입장 학생을 확인
5. 관리자 화면에서 시험시간을 최종 확인/수정
6. `시험 시작`을 누르는 순간 서버 시각 기준으로 공통 타이머 시작
7. 학생 화면은 자동으로 문항 화면으로 전환
8. 종료 시 자동 제출

## 중요
- 이번 버전은 Firestore Rules 변경이 필요합니다.
- 패키지의 `firestore.rules`를 Firebase Console > Firestore Database > Rules 에 전체 반영 후 게시하세요.
- Firebase Storage는 사용하지 않습니다.
