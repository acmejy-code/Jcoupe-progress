# 제이쿱 수업 통합 제어 시스템 v2.2.1

기존 v2.2.0의 Google Drive 수업 자료실 기능을 유지하면서, 자료실을 **전체 학생 공통 자료실**로 단순화한 전체 배포본입니다.

## v2.2.1 변경 사항

- 관리자 `수업 자료 등록/수정` 화면의 **반별 공개 대상 선택 UI 완전 제거**
- 모든 수업 자료를 자동으로 **전체 학생 공통 자료**로 저장·발행
- 자료 목록에서도 반별 대상 표시를 없애고 `공통 자료`로 표시
- Firestore 하위 호환성을 위해 `targetClasses: ["ALL"]` 필드는 계속 저장
- 기존 v2.2.0의 Google Drive 링크 등록, 미리 보기, 다운로드 확인, 공개/비공개, 수정/삭제 기능 유지
- 기존 수업 진도 관리의 A/B/C/E 반 구분 기능은 그대로 유지

## 자료실 운영 방식

1. Google Drive에 학생 배포 파일을 업로드합니다.
2. 파일 공유 설정을 `링크가 있는 모든 사용자 → 뷰어`로 설정합니다.
3. 관리자 시스템의 `수업 자료` 메뉴에서 **파일 자체의 공유 링크**를 등록합니다.
4. 시스템은 Firestore에 파일 자체가 아닌 자료 정보와 Drive 링크만 저장합니다.
5. 학생 포털 v1.2.1의 `수업 자료실`에는 반 선택 없이 공개 자료가 공통으로 표시됩니다.

## 배포

- 기존 `Jcoupe-progress` 저장소의 파일을 이 배포본으로 전체 교체합니다.
- GitHub Desktop에서 Commit → Push origin 합니다.
- GitHub Actions 배포 완료 후 관리자 페이지에서 `Ctrl + F5`로 새로고침합니다.
- 현재 적용한 Firestore 규칙은 그대로 사용하면 됩니다. **v2.2.1 때문에 Rules를 다시 수정할 필요는 없습니다.**
- 학생 포털은 `Jcoupe-class-portal v1.2.1`과 호환됩니다.

## 주의

- 자료 등록 시 Google Drive **폴더 링크가 아니라 개별 파일 링크**를 입력합니다.
- 관리자 시스템에서 자료를 삭제해도 Google Drive 원본 파일은 삭제되지 않습니다.
- Drive 파일의 공유 권한을 제한하면 학생 포털에서 항목이 보여도 파일을 열거나 다운로드할 수 없습니다.
