# JCOUP 수업 통합 제어 시스템 관리자 v2.6.0

기준: v2.5.3 공지·Google Drive 첨부 안정화 버전

## 주요 개선

### 수행평가 시험시간
- 수행평가 생성 시 '시험 시간(분)' 설정
- 교사가 [평가 시작]을 누르는 순간을 공통 시작 시각으로 사용
- 관리자 화면에 남은 시간 표시
- 전체 +5분 / +10분 연장
- 학생별 +5분 / +10분 연장
- 시간 만료 학생은 자동 제출 처리
- 제출 완료 학생을 교사가 '재응시 허용'으로 다시 열 수 있음

### 실시간 감독
- 학생 화면 이탈 감지
- 복사 / 붙여넣기 / 우클릭 기록
- 학생 카드에 이탈·복사·붙여넣기 횟수 표시
- 학생 카드의 ⋯ 버튼에서 시간순 감독 이벤트 확인
- 감독 이벤트는 참고 기록이며 자동으로 부정행위를 확정하지 않음

### 접속 상태 판정 개선
- 학생 heartbeat 주기: 약 15초
- 45초 이내: 정상 응시중
- 45~100초: 연결 지연(노란색)
- 100초 초과: 접속 이상(빨간색)
- 기존보다 일시적 지연을 접속 이상으로 오판하는 빈도를 낮춤

### 4자리·5자리 학번
- 학생 포털에서 4자리·5자리 입력 모두 허용
- 실제 명단이 5자리인 경우에도 대표적인 4자리 형식을 자동 후보로 변환하여 인증 시도
- 관리자 명단 원본은 변경하지 않음

### 진도 달력 연계
- 이전 수업 기록의 '다음 시간 시작점'을 해당 반의 다음 실제 예정 수업 카드에 표시
- 예: `↪ 다음: 수치예보 3문단부터`
- 휴업일과 수동 숨김/미진행 수업은 건너뜀
- 실제 진도 기록이 작성되면 예정 카드가 실제 기록으로 대체됨

## 기존 기능 유지
- 공지: 일반 공지 / 수행평가 공지
- 공지 첨부: Google Drive 공유 링크
- Firebase Storage 미사용
- 세로 한 줄 좌석 배치
- 복도쪽/외벽 창가 표시
- 학생 화면 테스트 새 창
- 응답 CSV
- 테스트 기록 초기화

## Firebase
이번 v2.6.0에서 Firestore Rules 변경은 필요하지 않습니다.
현재 v2.5.x 공지 기능용 Firestore Rules를 그대로 유지하면 됩니다.
