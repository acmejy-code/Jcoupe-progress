수업 프로젝트
학년도·학기·학년·과목이 달라져도 같은 시스템 안에서 누적 관리합니다.
형식: 반@교시를 쉼표로 구분합니다. 예: A@3, E@6, B@7
수업 자료 등록
Google Drive 파일의 공유 링크를 등록합니다. 파일 자체는 Firebase에 저장하지 않습니다.
※ Drive에서 반드시 링크가 있는 모든 사용자 → 뷰어로 공유한 뒤 링크를 붙여 넣으세요.
새 공지 작성
일반 공지와 수행평가 공지를 학생 포털에 게시합니다. 첨부파일은 Google Drive 공유 링크로 연결합니다.
① Drive에 파일 업로드 → ② 링크가 있는 모든 사용자 · 뷰어로 공유 → ③ 파일명과 공유 링크를 등록하세요. 한 공지에 최대 5개까지 연결할 수 있습니다.
수행평가 만들기
응시코드는 학생별 번호가 아니라 교실에서 공통으로 사용하는 평가 입장 코드입니다.
교사가 [평가 시작]을 누르는 순간부터 모든 학생에게 같은 시간이 적용됩니다.
학생 명단 · 좌석 배치
명단을 불러온 뒤 실제 교실 책상 배열과 같게 좌석을 직접 저장할 수 있습니다.
칠판에서 교실 뒤쪽으로 한 세로줄에 배치할 좌석 수입니다. 예: 4 → 한 세로줄에 앞→뒤 4석, 좌우 열 수는 학생 수에 맞춰 자동 계산됩니다.
Excel(.xlsx/.xls), CSV, TSV, TXT 파일을 불러올 수 있습니다. 위쪽에 교시·학급 정보가 있어도 '학번/이름' 또는 '학년/반/번호/이름' 머리글 행을 자동으로 찾아 인식합니다.
※ [명단 적용]은 선택 반의 기존 명단을 교체하고 학번 오름차순의 기본 좌석을 만듭니다. 적용 후 바로 [좌석 배치] 탭에서 실제 교실 배열을 저장할 수 있습니다.
좌석 배치
학생 카드를 드래그해 실제 자리에 맞추세요. 빈 자리는 저장되며 수행평가 실시간 감독 화면에도 그대로 표시됩니다.
칠판 · 교탁 (교실 앞)
빈 자리의 ×를 누르면 해당 빈칸만 삭제할 수 있습니다. 학생 카드를 빈 자리 위로 끌어 놓으면 서로 자리가 바뀝니다.
학생 화면 테스트
선택한 학생의 실제 학생 포털 화면을 새 창으로 엽니다. 관리자 화면과 로그인 상태는 그대로 유지되며, 테스트 답안은 서버에 저장되지 않습니다.
버튼을 누르면 별도의 학생 테스트 창이 열립니다. 관리자 창은 그대로 두고 두 화면을 나란히 확인할 수 있으며, 테스트 창에서 작성·제출한 내용은 실제 학생 답안이나 감독 현황에 저장되지 않습니다.
학생 감독 기록
응시 상태와 감독 이벤트를 확인합니다.
화면 이탈·복사·붙여넣기 기록은 감독 참고 자료입니다. 해당 기록만으로 부정행위를 자동 확정하지 않습니다.
온라인 동기화 설정

Firebase 설정 전에는 이 기기에 저장됩니다.

Firebase + Google 로그인을 사용하면 학교 PC, 집 PC, 휴대폰에서 같은 수업 프로젝트와 기록을 동기화합니다.

  1. js/firebase-config.js의 Firebase 웹 앱 구성값을 확인합니다.
  2. Firebase Authentication에서 Google 로그인을 켭니다.
  3. Firestore에 제공된 firestore.rules를 적용합니다.
  4. GitHub Pages로 배포합니다.
