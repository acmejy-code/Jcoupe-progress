현재는 Firebase 설정이 비어 있어 이 기기에 저장됩니다.

GitHub Pages + Firebase 설정을 한 번 완료하면 학교 PC, 집 PC, 휴대폰에서 같은 Google 계정으로 로그인해 동일한 기록을 볼 수 있습니다.

  1. js/firebase-config.js에 Firebase 웹 앱 구성값을 입력합니다.
  2. Firebase Authentication에서 Google 로그인을 켭니다.
  3. Firestore를 만들고 제공된 firestore.rules를 적용합니다.
  4. GitHub에 올리면 포함된 Actions가 Pages에 자동 배포합니다.

자세한 순서는 프로젝트의 README_처음설정.md를 그대로 따라가면 됩니다.
