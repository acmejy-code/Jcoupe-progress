Jcoupe 수행평가2 보충 응시 관리 업데이트
관리자 v3.5.4 / 학생 v1.8.6

[기준 버전]
- 관리자: v3.5.2 수행평가2 정식통합 전체교체본
- 학생: v1.8.5 CONNECTION_FIX_FLAT_WINDOWS_SAFE
- Drive Bridge: v1.0.1 그대로 사용(변경 없음)

[핵심 기능]
1. 기존 평가를 새로 만들지 않고 같은 평가ID에서 보충 응시를 허용합니다.
2. 관리자 수행평가2 모니터 표에서 학생을 체크하여 개별 보충 권한을 부여합니다.
3. 2차시 보충 열기/닫기, 3차시 보충 열기/닫기를 지원합니다.
4. '2차시 미제출 선택', '3차시 미제출 선택' 버튼으로 대상자를 빠르게 선택할 수 있습니다.
5. 기존 2차시 작성중 기록이 있으면 그대로 이어 쓰며, 완전 미접속 학생은 같은 평가ID에 새 2차시 기록을 생성합니다.
6. 이미 2차시를 최종 제출한 학생은 보충창이 열려도 제출 잠금이 유지됩니다.
7. 3차시 보충은 2차시 최종 제출 완료 학생만 입장할 수 있습니다.
8. 학생별 보충 대상 명단은 공개 평가 문서에 노출하지 않습니다. 공개 문서에는 반별 보충창 열림 여부만 저장합니다.

[적용 순서 - 중요]
1. Firebase Console 또는 Firebase CLI에서 새 firestore.rules를 먼저 배포합니다.
2. 관리자 사이트 파일을 v3.5.4 전체교체본으로 교체하여 배포합니다.
3. 학생 사이트 파일을 v1.8.6 전체교체본으로 교체하여 배포합니다.
4. 기존 Drive Bridge v1.0.1은 건드리지 않습니다.
5. 관리자 화면에서 기존 수행평가2를 선택하고 반을 선택합니다.
6. '2차시 미제출 선택' 또는 학생 개별 체크 후 '2차시 보충 열기'를 누릅니다.
7. 학생은 기존 수행평가 카드의 '2차시 보충 응시' 버튼으로 학번·이름·기존 응시코드를 입력합니다.
8. 제출 완료를 확인한 뒤 해당 학생을 선택해 '2차시 보충 닫기'를 누릅니다.

[현재 상황 권장 운영]
- 아직 반 단계가 '추가자료 등록'이라면: 2차시 보충 제출 직후 학생이 포털로 돌아가 일반 '추가자료 등록' 메뉴를 이용할 수 있습니다.
- 반이 이미 '3차시 진행' 또는 '완료'라면: 2차시 보충 자체는 가능하지만 추가자료 등록기간은 별도로 다시 열리지 않습니다. 필요한 경우 추가자료 보충 권한 기능을 후속으로 추가할 수 있습니다.

[데이터 보존]

- 기존 phase2/phase3 답안 유지
- 기존 extraMaterials 유지
- 기존 제출 시각/상태 유지
- Firebase 프로젝트 및 기존 컬렉션 초기화 없음
