Jcoupe-progress v3.5.4 — 수행평가2 교사 제공 자료 링크 간편 입력

기준 버전
- 관리자 v3.5.3 보충 응시 관리
- 학생 포털은 v1.8.6 그대로 사용

변경 사항
1. 기존 ‘자료명 | URL’ 한 줄 입력 방식을 제거했습니다.
2. 각 지문·논제 카드에 자료명과 URL을 별도 칸으로 표시합니다.
3. 새 평가에서는 기본으로 ‘원지문’, ‘보조자료’ 두 줄이 생성됩니다.
4. 사용자는 URL 칸에 Google Drive PDF 링크만 붙여넣으면 됩니다.
5. 필요하면 ‘+ 자료 추가’로 교사 제공 자료를 더 연결할 수 있습니다.
6. 기존 평가에 이미 저장된 teacherMaterials도 같은 행 방식으로 불러옵니다.
7. 저장 데이터 구조는 기존 teacherMaterials[{id,title,url}]를 그대로 유지하므로 학생 v1.8.6 수정은 필요 없습니다.

적용
- 관리자 v3.5.4 전체 파일로 교체 후 재배포
- 학생 포털, Firestore Rules, Drive Bridge는 이번 변경으로 교체할 필요 없음
