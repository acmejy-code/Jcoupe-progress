# Jcoupe-progress v3.5.4 — 보충 응시 관리

기준: v3.5.2 수행평가2 정식통합 전체교체본

## 추가 기능
- 수행평가2 반별 모니터 표에서 학생 선택 가능
- 2차시 미응시 학생 자동 선택
- 3차시 미제출 학생 자동 선택
- 선택 학생에게 2차시 보충 응시 열기/닫기
- 선택 학생에게 3차시 보충 응시 열기/닫기
- 기존 평가ID와 학생 기존 기록은 유지
- 학생별 보충 권한은 관리자 전용 평가 문서(makeupAccess)에 저장
- 학생 공개 평가 문서에는 반별 보충창 열림 여부(makeupWindows)만 공개

## 중요
이 버전은 학생 v1.8.6 및 포함된 firestore.rules와 함께 적용해야 합니다.
Drive Bridge v1.0.1은 변경하지 않습니다.
